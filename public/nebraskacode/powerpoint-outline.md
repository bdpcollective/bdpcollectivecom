## Slide 13 — The Prompt Feedback Loop

**Title:** The Prompt Feedback Loop
**Pipeline visual:** Prompt → Review Output → Refine Prompt → Better Output → (loop arrow)

**Four cards in a 2×2 grid:**

**Card 1:**
- **1. Start Broad**
- "Design a dashboard for a fitness app." Get the general direction. Don't over-specify on the first pass.

**Card 2:**
- **2. Evaluate & React**
- What's working? What's off? Name the specific thing — "the layout is right but the hierarchy is flat."

**Card 3:**
- **3. Add Constraints**
- "Make the progress ring larger. Move quick-add to the bottom. Use our 8px grid." Each constraint sharpens the output.

**Card 4 (green border, highlighted):**
- **4. Converge**
- After 2–3 loops you have something worth building on. The feedback loop replaces the blank canvas.

**Visual:** Pipeline flow at top, 2×2 card grid below. Card 4 has green accent border.

**Script:** "Prompting isn't a one-shot thing — it's a feedback loop. Start broad, evaluate what comes back, add constraints to sharpen the output, and after two or three loops you've got something worth building on. Each constraint you add focuses the AI. And your prompting skill improves with every loop — it's a skill like any other."

## Design Specifications (DevObsessed Brand)

**Color Palette:**
| Token | Hex / Value | Usage |
|---|---|---|
| Background | `#0a0f1a` | Slide background (dark mode primary) |
| Primary Text | `#f5f5f7` | Headlines, body copy |
| Brand Green | `#34c759` | Accent, CTAs, section labels, links, bullet dots |
| Text Dim | `#8da3b8` | Secondary body text, descriptions |
| Text Faint | `#8a97a5` | Subtle hints, footers, metadata |
| Warning Red | `#ff6c6c` | Limitations, rejections, "bad at" items |
| Glass BG | `rgba(255,255,255,0.03)` | Frosted glass card backgrounds |
| Glass Border | `rgba(255,255,255,0.06)` | Card and element borders |
| Green Faint | `rgba(52,199,89,0.1)` | Accent backgrounds, badge fills |
| Focus Ring | `#a855f7` (purple) | Keyboard focus indicators (accessibility) |

**Typography:**
| Role | Typeface | Size (slides) | Usage |
|---|---|---|---|
| Headlines (h1/h2) | DM Serif Display, 400 | 40-56pt | Page titles, section headings |
| Subheadings (h3) | DM Serif Display, 400 | 28-36pt | Card titles, slide subtitles |
| Body / UI | Inter, 400-500 | 24-28pt | Body copy, bullets, descriptions |
| Section Labels | Space Grotesk, 500, uppercase | 12-14pt | Section divider labels (with green dot prefix, 0.1em tracking) |
| Card Labels | Space Grotesk, 600, uppercase | 11-13pt | Card header labels (0.08em tracking) |
| Stat Numbers | Space Grotesk, 700 | 48-54pt | Big numbers (e.g., "80%") |
| Code/Prompts | JetBrains Mono, 400 | 18-22pt | Prompt examples, code snippets |
| Quotes | DM Serif Display, italic | 32-40pt | Pull quotes (with 3px green left border) |

**Glassmorphism (Card Treatment):**
Every card/container should use this layered treatment:
1. Background: `rgba(255,255,255,0.03)` (Glass BG)
2. Border: `1px solid rgba(255,255,255,0.06)` (Glass Border)
3. Top border: `1px solid rgba(255,255,255,0.08)` (gradient top-lit edge)
4. Border radius: `24px` (bento cards) or `20px` (standard glass)
5. Noise texture overlay at 3% opacity (fractal noise)
6. Backdrop blur: 20px with 180% saturation

**Component Patterns:**
- Section labels: Green dot (8px circle) + uppercase text in Space Grotesk, Brand Green
- Bullet points: Green dots instead of traditional bullets
- Badges/pills: 100px radius (full pill), green-faint background, green border
- Buttons: Pill shape (100px radius), glass background
- Selected cards: Green border `rgba(52,199,89,0.3)` + green glow shadow
- Rejected cards: Red border at low opacity, 50% overall opacity

**Background Grid:**
- 80px square grid pattern at 1.8% white opacity behind all slide content
- Creates subtle depth without distraction

**Slide Dimensions:** 16:9 (1920x1080 or 1280x720)

**Rules:**
- Max 5-6 bullet points per slide
- No walls of text — details go in speaker notes
- Every demo slide should have the actual output embedded
- Use green accent sparingly — primarily for CTAs, labels, and interactive highlights
- Never use green for error states or destructive actions (use warning red)
- All section divider slides should have the green dot + section label pattern
- Use DM Serif Display for ALL headings — never Inter or Space Grotesk for h1/h2
- Card titles use Space Grotesk (uppercase), not DM Serif Display
